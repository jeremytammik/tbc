New Year, New Home for The Building Coder

Happy New Year, everyone!

This is my first post since retiring in June 2025.

While I’ve been busy with real life, the Revit API community hasn't stood still, and neither has The Building Coder.

End of the Typepad Era

Shortly after my retirement, Typepad was discontinued, and The Building Coder main site disappeared with it. That is not nice at all. In the ideal web, a URL is a permanent promise. Unfortunately, platforms like Typepad don't always share that philosophy. When Typepad discontinued, the original TBC site vanished. Luckily, the Revit API community includes enthusiasts who value persistence.

Mirrors: Long Live The Building Coder

The king is dead, long live the king!

Luckily, I started publishing and maintaining all The Building Coder source code on GitHub twelve years ago in the tbc repository as well as publishing a rough index of all posts via GitHub pages.

Based on that repo, at least two fresh copies were published:

  • The Building Coder on ArchiLabs.ai by ArchiLabs.ai
  • The Building Coder on AecWithCode.com by Tomo Sugeta

Rebirth: TBC is Live and Portable

Just in time for 2026, Francis Sebastian (@parametrix) of SOM completely reinvigorated the project. His contributions move TBC from a static archive to a modern, portable resource:

  • Offline browsing: obsolete Typepad links converted to local paths, enabling hosting and browsing the entire archive without an Internet connection.
  • Reimplemented index: the tbc GitHub pages now feature a fully functional chronological index and topic group browser.
  • Automation: Python scripts now support seamless addition of new posts and management of topic groups.

It feels great to see this Revit API knowledge collection preserved and improved by the very people who use it.

Ever so many thanks to ArchiLabs, Tomo, and especially Francis for their incredible work and support!

So, now let's try it out...
